    Simulation parser mapping report¶

    This report is generated with create_mapping_table by comparing the quantities declared in the simulation file parsers with the source paths used by their archive mappers.

    The report is a snapshot of the mapper configuration. To inspect another file parser, call create_mapping_table(file_parser, archive_parser) from nomad_simulation_parsers.parsers.utils.general and serialize the returned rows as Markdown or another table format.

    Optional manual corrections can be supplied with nomad-sim-parser mapping-report --override <file.yaml>; see docs/reference/parser_mapping_report_overrides.yaml for the format.
